# Bulk RNA-seq analysis of SARS-CoV-2 PBMC samples

The working source is [analysis/bulk_analysis.Rmd](analysis/bulk_analysis.Rmd). It consumes GSE152418 gene counts and GEO-derived metadata, performs DESeq2 with apeglm shrinkage, and reports GO enrichment with identifier-mapping audits.

The original cohort has 34 libraries. The historical Infected label includes 16 acute COVID-19 libraries and one convalescent library; 17 libraries are healthy controls. Repeat-draw identifiers are present. The condition-only model is preserved as an **exploratory reproduction**; its p-values do not resolve donor dependence or confounding.

## Run and validate

Use R 4.5.2 with the packages in [provenance/package_versions.csv](provenance/package_versions.csv), plus Pandoc. This package list is a historical environment record, not an isolated lockfile. R entry points prefer an existing repository-local `.r-library/`; shared libraries are read only. No script installs packages. See [dependency and runtime guidance](docs/VALIDATION.md#runtime-and-dependencies).

Python validation requires Python 3.11 or newer (standard library only).

From this repository:

~~~sh
Rscript --vanilla scripts/validate.R
python scripts/validate_repository.py
Rscript --vanilla tests/test_render.R
Rscript --vanilla scripts/check_environment.R
Rscript --vanilla scripts/render.R --preflight
Rscript --vanilla scripts/render.R
~~~

The render produces outputs/bulk/report/bulk_analysis.html, result tables, figures, DESeq2/VST objects, session records, and SHA-256 input/output manifests. Output directories are ignored by Git. The runner sets the project root, records relative manifest paths, and keeps outputs separate from inputs. It refuses to overwrite a nonempty run directory; deliberately archive a previous run before starting a new one. `--preflight` checks dependencies and input availability without running the analysis.

The completed local report from 2026-09-05 was preserved and its five input hashes and 22 output hashes were verified during maintenance. It still contains numerical and presentation warnings documented in [validation](docs/VALIDATION.md). It is not regenerated by the infrastructure smoke test.

To explicitly refresh metadata from the primary GEO series matrix:

~~~sh
python scripts/refresh_geo_metadata.py --check  # offline comparison; changes nothing
python scripts/refresh_geo_metadata.py          # explicit online refresh
~~~

The snapshot and retrieval record are retained in provenance/. The tracked count matrix agrees with the original after line-ending normalization.

## Files and evidence

- [data/metadata/geo_samples.csv](data/metadata/geo_samples.csv): GEO disease state, severity, sex, timing, GSM accession, and original analysis label.
- [reference/tables](reference/tables): historical local exports, including 3,879 significant genes (3,688 higher and 191 lower). Membership and top-gene ranking were independently checked.
- [reference/remote_tables](reference/remote_tables): previous GitHub table versions.
- [reference/figures](reference/figures): historical figures, not regenerated images.
- [docs/AUDIT.md](docs/AUDIT.md): findings, lineage, changes, and unresolved scientific questions.
- [docs/VALIDATION.md](docs/VALIDATION.md): actual checks and rerun status.
- [provenance/original_workspace_manifest.csv](provenance/original_workspace_manifest.csv): baseline hashes of all 83 read-only original files.

New enrichment uses all finite shrunken effects, including genes without adjusted p-values. Ambiguous one-to-many Ensembl-to-Entrez mappings are excluded; multiple genes mapping to one Entrez ID are resolved by largest absolute effect, with Ensembl ID as tie-breaker. All candidates and selected ranks are exported. These changes can alter enrichment relative to the historical output.

Bulk expression does not establish cellular sources, pathway activation, or causality. Clinical cohort revision and repeat-donor handling remain prerequisites for stronger disease inference.
